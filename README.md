# 南京工程学院 · 学生评教批量助手（NGC-ZDPJ）

南京工程学院教务系统（正方）学生评教的批量填写工具。走学校统一身份认证登录，自动进入评教页面，按配置批量选择评价选项、生成评语并提交。

单文件 exe，内置浏览器内核，目标机器**不需要装 Python、不需要装 Chromium**。

## 功能

- 统一身份认证自动登录（账号密码 + 验证码 OCR 识别，可切换第三方打码平台）
- 自动进入评教列表，逐门课程填写
- 评价选项可配置：默认项、指定题目单独选项、最后一题单独选项
- 评语自动生成，长度可限，同一批次内不重复
- 多账号批量：一次添加多个学号，按并发数同时跑
- 已评课程自动跳过，支持「课程评估」与「学生评教」两种页面
- 网页控制台实时日志，关窗即退出

## 使用教程

### 一、准备

1. Windows 10 / 11，能正常访问学校信息门户。
2. 关闭杀毒软件的「下载拦截」——单文件 exe 未做商业签名，容易被误报，添加信任即可。

### 二、启动

双击 `NGC-ZDPJ.exe`，会弹出一个黑色命令行窗口，并自动打开浏览器：

```
http://127.0.0.1:8765/
```

如果浏览器没自动打开，手动访问这个地址即可。**黑窗口不要关**，关了程序就退出。

### 三、添加账号

在左侧「账号」区域：

| 字段 | 说明 |
|---|---|
| 学号 | 统一身份认证的学号 |
| 密码 | 信息门户密码，仅保存在本机 `data\` 目录 |
| 并发 | 同时处理几个账号，建议 1~2，太多容易被系统限流 |

点「添加」把账号加进列表。多个账号重复添加即可。

### 四、配置评价策略

在 `config.json` 里（程序首次运行会在同目录生成）：

| 字段 | 默认 | 说明 |
|---|---|---|
| `default_option` | `非常满意` | 所有题目的默认选项 |
| `special_option` | `比较满意` | 指定题目用的选项 |
| `special_keywords` | 见文件 | 命中这些关键词的题目用 `special_option` |
| `last_question_option` | `非常满意` | 最后一道题的选项 |
| `comment_enabled` | `true` | 是否自动生成评语 |
| `max_comment_len` | `200` | 评语最大长度 |
| `auto_break_consistency` | `true` | 打散选项分布，避免全选同一个 |
| `skip_submitted` | `true` | 已提交的课程跳过 |
| `delay_min` / `delay_max` | `700` / `1600` | 每步操作间隔（毫秒），随机取值 |
| `auto_submit` | `true` | 填完自动提交；设为 `false` 只保存不提交 |
| `headless` | `false` | 是否无头运行，`false` 能看到浏览器操作过程 |
| `captcha_mode` | `ocr` | `ocr` 本地识别 / `platform` 第三方打码 |

可选：`config.example.json` 是脱敏模板，复制成 `config.json` 再改。

### 五、开始执行

点右上角「开始」，控制台会实时打印：

```
[学号] 登录成功
[学号] 可评价教学班: 保存 0 门次, 提交 19 门次, 未评 0 门次
[学号] TOTAL=19  SUBMITTED=19
```

跑完看到 `SUBMITTED` 数量等于课程数，就是全部提交成功。

### 六、退出

直接关掉浏览器窗口，程序 3~5 秒后自动退出，黑窗口一起消失。

| 操作 | 结果 |
|---|---|
| 关掉网页窗口 | 程序 3~5 秒后退出 |
| 关掉黑窗口 | 网页显示「程序已退出」并自动关闭 |
| 刷新页面 | 不会退出（有 4 秒宽限） |
| 开多个标签页 | 全部关完才退出 |

## 从源码运行

```bash
python -m pip install -r requirements.txt
python prep_browsers.py      # 准备内置浏览器（约 280MB）
python pj.py                 # 命令行模式
python server.py             # 网页控制台模式，默认 8765 端口
```

可选参数：

```bash
python server.py --port 9000        # 换端口
python server.py --no-browser       # 不自动打开浏览器
```

## 常见问题

**Q：双击没反应 / 一闪而过**
用命令行运行 `NGC-ZDPJ.exe`，能看到具体报错。多数是杀毒软件拦截或缺少 VC 运行库。

**Q：登录一直失败**
先在浏览器里手动登录一次信息门户，确认账号密码正确、验证码能正常显示。若开启了第三方打码平台，检查 `captcha_platform` 里的账号密码。

**Q：提示「未检测到评教任务」**
评教通常有开放时间窗口，未开放时列表为空。也可能是已经全部评完。

**Q：提交后分数不对**
检查 `special_keywords` 是否命中了不该命中的题目；把 `auto_submit` 设为 `false` 先跑一遍看结果，确认无误再开启自动提交。

**Q：会不会上传我的账号**
不会。所有账号信息只写在本机 `data\` 目录，程序不联网上报任何数据。唯一的外发请求是访问学校教务系统和（可选）验证码识别接口。
